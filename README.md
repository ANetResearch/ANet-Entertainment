# 流浪地球番外 · 未熄之网

围绕 [Agent Network (ANET)](https://agentnetwork.org.cn/) 的 12 集伪纪录片体科幻科普短剧素材库。
故事贴着《流浪地球》的事件线（2058 互联网重启 → 2075 木星危机 → 点燃木星）讲一条原创支线：
MOSS 沉默之后，一群小人物用回收的旧机器搭起一张不属于任何人的网，把孤立的地下城重新连了起来。

所有镜头**没有字幕、没有旁白**，提示词要求不配乐，只保留现场对白和环境声，供后期统一配字幕和 BGM。
是否混入了配乐由模型自动试听判断，结果见各集 `audio_qc.json`，建议人工复听。

## 目录

| 路径 | 内容 |
|---|---|
| `series/bible.md` | 系列设定：世界观、人物、分集大纲、提示词规范 |
| `series/epNN.json` | 每集分镜脚本：镜头时长、分镜图提示词、视频描述、现场对白、旁白建议（`vo`）、模板字段（`tpl`） |
| `refs/` | 人物、场景、道具参考图，`refs.json` 是索引 |
| `assets/logos/` | ANET 笑脸标志、Agent Network 字标、AutoDL 标志 |
| `episodes/epNN/clips/` | 每个镜头选用的一条原始视频，`epNN_sNN.mp4`，按镜头号顺序剪即可 |
| `episodes/epNN/alt/` | 同一镜头的其他条（备选） |
| `episodes/epNN/storyboard/` | 分镜图（JPEG） |
| `episodes/epNN/prompts/` | 每条视频实际提交的完整提示词、随机种子和输入图列表 |
| `episodes/epNN/script.json` | 该集分镜脚本副本 |
| `episodes/epNN/audio_qc.json` | 自动试听结果：听到的对白、是否疑似有配乐、标记 |
| `tools/` | 生成流水线脚本（`config.example.json` 填入自己的密钥后改名为 `config.json`） |

## 短片《未熄》

约 12 分 30 秒、82 个镜头的独立短片，把 12 集的故事压成一部：人类的赞歌就是勇气的赞歌，ANET 是具身智能与人类智能的团结。

| 路径 | 内容 |
|---|---|
| `film/TREATMENT.md` | 创作说明：立意、三个贯穿意象、五段结构与节奏、音乐编排 |
| `film/weixi-roughcut.mp4` | 按镜头顺序拼的粗剪（无字幕、无配乐，1024 宽压缩版） |
| `film/roughcut_takes.json` | 粗剪每个镜头用的是哪一条 |
| `film/build_film.py` | 生成分镜脚本 `series/ep13.json` 的脚本 |
| `episodes/ep13/` | 短片的原始片段（`clips/` 选用条，`alt/` 备选条）、分镜图、提示词、试听结果 |
| `tools/gen_music.py` | 主题音乐与三首歌（《未熄》《勇气的赞歌》《螺丝》）的曲目提示词和歌词 |

## 制作方式

- 视频：AutoDL 上的 MiniMax H3（`minimax_h3_adl_int8`），768p 横屏，单镜头 6–15 秒，原生带声音。
- 每条视频的输入图 = 该镜头分镜图 + 随机若干张参考图，总数随机 2–5 张。
- 分镜图与参考图：gpt-image-2.6-sunburst，伪纪录片画面风格。
- 对白准确性与配乐情况由脚本自动转写检查，见 `audio_qc.json`。

本片为同人性质的番外创作，人物与情节均为原创，不代表《流浪地球》官方。
