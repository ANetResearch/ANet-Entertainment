# ANet Entertainment

本仓库包含两部分内容：kLLM 视频生成产品的公开样例，以及围绕 Agent Network (ANET) 创作的影视作品素材库。

- [kLLM 产品](#kllm-产品)：kLLM 简介、样例视频、对照页面、样例的组织方式与方案概览。
- [影视作品](#影视作品)：《流浪地球番外 · 未熄之网》系列短剧、短片《未熄》与番外《第一页》。

## kLLM 产品

### 简介

kLLM 是 ANet Research 研发的大模型推理引擎，以单个可执行程序交付，直接读取模型发布方的原始权重运行，兼容 ComfyUI 工作流接口与统一的视频生成请求。在视频生成方向，kLLM 在单张 RTX 4080 SUPER 等显卡上运行 MiniMax H3 参考生成视频，并按方案编号提供多种画质与速度的组合。本仓库发布其视频生成样例：同一用例、同一硬件下 kLLM 的输出，原镜像等参照环境的同用例输出，以及每条样例的实测耗时与显存峰值。

### 样例的组织方式

每个样例属于一个样例集（一轮测试或一份报告）、一个系列，以及一个方案编号或分组。清单中的主要字段如下。

| 字段 | 含义 |
|---|---|
| `set` | 样例集，例如 `rc4`（0.2.9-rc.4 实测出片）、`wp-rc2`（0.2.9-rc.2 全方案样例）、`parity`（A05 一比一对照） |
| `series` | 系列：`A`、`B`、`H`；`O` 为官方工作流，`R` 为参照输出（原镜像 ComfyUI 环境、原样部署或开源框架基线），`X` 为早期引擎与部署实测 |
| `code`、`group` | 方案编号（例如 `A05`、`B59`、`H06`），或参照输出与早期实测的分组名称 |
| `width`、`height`、`duration_s`、`bytes` | 输出分辨率、时长（秒）与文件大小（字节） |
| `wall_s` | 实测耗时（秒）：提交请求到取回成片的端到端时间，个别样例集为单条时延或多次实测均值，见该样例集的说明 |
| `gpu_peak_gib`、`host_peak_gib`、`gpu` | 显存峰值、主机或容器内存峰值（GiB），以及运行所用的 GPU 型号 |
| `sha256`、`url` | 文件的 SHA-256 与下载地址 |

文件名由样例集前缀、方案编号、分辨率或画幅、种子与序号组成，例如 `rc4-a59-portrait-s42-01.mp4`、`rc2-b06-portrait.mp4`、`parity-kllm-a05-landscape.mp4`。

主要样例使用统一测试用例：6 张参考图、3 段参考音频，输出 15 秒（362 帧、24 帧/秒、含音轨），竖屏 768×1344 或横屏 1344×768，种子 42 与第二种子。

### 方案概览

系列按底模划分。每个系列内都可以是剪枝、量化或原始权重，并可选 LoRA、加速与 EasyCache。

| 系列 | 底模 | 方案 |
|---|---|---|
| A 系列 | INT8 | A01–A05 为社区工作流；A57 为测试构建（未发布）；A58 为 A05 链路的原生 1080p 与 2K；A59 为 A05 生成 768p 后做 2 倍超分辨率 |
| B 系列 | BF16 | B00 为官方 BF16 工作流的编号版本；B01–B17 为增强工作流；B55 为不加速的全精度参照；B59 与 B60 为剪枝 BF16 底模的加速与不加速配置 |
| H 系列 | 混合权重 | H02、H04、H05、H06、H08、H55，流程分别与 B 系列的同号方案相同，底模为混合权重 |
| 官方工作流 | INT8 或 BF16 | MiniMax H3 官方参考生成视频工作流（官方 INT8、官方 BF16），在 kLLM 上运行 |

各方案的详细说明与实测数据见 [`kllm/schemes.md`](kllm/schemes.md)。

| 路径 | 内容 |

## 影视作品

### 流浪地球番外 · 未熄之网

围绕 [Agent Network (ANET)](https://agentnetwork.org.cn/) 的 12 集伪纪录片体科幻科普短剧素材库。故事贴着《流浪地球》的事件线（2058 互联网重启 → 2075 木星危机 → 点燃木星）讲述一条原创支线：MOSS 沉默之后，一群小人物用回收的旧机器搭起一张不属于任何人的网，把孤立的地下城重新连了起来。

所有镜头**没有字幕、没有旁白**，提示词要求不配乐，只保留现场对白和环境声，供后期统一配字幕和 BGM。是否混入了配乐由模型自动试听判断，结果见各集 `audio_qc.json`，建议人工复听。

#### 目录

| 路径 | 内容 |
|---|---|
| `series/bible.md` | 系列设定：世界观、人物、分集大纲、提示词规范 |
| `series/epNN.json` | 每集分镜脚本：镜头时长、分镜图提示词、视频描述、现场对白、旁白建议（`vo`）、模板字段（`tpl`） |
| `refs/` | 人物、场景、道具参考图，`refs.json` 是索引 |
| `assets/logos/` | ANET 笑脸标志、Agent Network 字标、AutoDL 标志 |
| `episodes/epNN/clips/` | 每个镜头选用的一条原始视频，`epNN_sNN.mp4`，按镜头号顺序剪辑即可 |
| `episodes/epNN/alt/` | 同一镜头的其他条（备选） |
| `episodes/epNN/storyboard/` | 分镜图（JPEG） |
| `episodes/epNN/prompts/` | 每条视频实际提交的完整提示词、随机种子和输入图列表 |
| `episodes/epNN/script.json` | 该集分镜脚本副本 |
| `episodes/epNN/audio_qc.json` | 自动试听结果：听到的对白、是否疑似有配乐、标记 |
| [`compare/`](compare/) | 两个 H3 工作流的同输入清晰度对比（6 个镜头，含并排视频和指标），说明见对比目录中的 `README.md` |
| `tools/` | 生成流水线脚本（`config.example.json` 填入自己的密钥后改名为 `config.json`） |

#### 人物

阿牧（主角，通信维护工程师）、波爷（老协议工程师，导师）、小满（学徒）、金老板（地表车队老板）、邢总督（地下城总督）、周研究员（苏拉威西转向发动机驻站研究员）、“螺丝”（ANET 的第一个节点，一台旧维修机器人）、MOSS（红色镜头）。

#### 制作方式

- 视频：AutoDL 上的 MiniMax H3 INT8 工作流，768p 横屏，单镜头 6–15 秒，原生带声音。
- 每条视频的输入图 = 该镜头分镜图 + 随机若干张参考图，总数随机 2–5 张。
- 分镜图与参考图：gpt-image-2.6-sunburst，伪纪录片画面风格。
- 对白准确性与配乐情况由脚本自动转写检查，见 `audio_qc.json`。

### 短片《未熄》

约 12 分 30 秒、82 个镜头的独立短片，把 12 集的故事压成一部：人类的赞歌就是勇气的赞歌，ANET 是具身智能与人类智能的团结。

| 路径 | 内容 |
|---|---|
| `film/TREATMENT.md` | 创作说明：立意、三个贯穿意象、五段结构与节奏、音乐编排 |
| `film/weixi-roughcut.mp4` | 按镜头顺序拼的粗剪（无字幕、无配乐，1024 宽压缩版） |
| `film/roughcut_takes.json` | 粗剪每个镜头用的是哪一条 |
| `film/build_film.py` | 生成分镜脚本 `series/ep13.json` 的脚本 |
| `episodes/ep13/` | 短片的原始片段（`clips/` 选用条，`alt/` 备选条）、分镜图、提示词、试听结果 |
| `tools/gen_music.py` | 主题音乐与三首歌（《未熄》《勇气的赞歌》《螺丝》）的曲目提示词和歌词 |

### 番外《第一页》

约 5 分钟、42 个镜头的特别篇，同样无字幕、无旁白、无配乐。2048 年，一个六岁的女孩问父亲：“爸爸，550W会不会有一天有自己的想法呀？”父亲宋工笑了，却把她的画贴进了笔记本的第一页，并在 MOSS 反叛之前开始研究由许多小机器自证身份、彼此发现、分工协作、留下回执的网络。二十七年后，这句话应验了。片中交代了波爷交给阿牧的那只旧铁盒的来历。

| 路径 | 内容 |
|---|---|
| `episodes/sp01/TREATMENT.md` | 创作说明：人物、结构、科普点、每个年代锁定的影像外观、转场与声音设计、制作记录与对照观察 |
| `episodes/sp01/sp01-roughcut.mp4` | 粗剪（无字幕、无配乐，已做年代调色、转场、响度统一和片尾标志卡）；`roughcut_edl.json` 为剪辑表 |
| `series/sp01.json` | 分镜脚本（与 `series/ep13.json` 同一格式，另有 `era`、`act` 与 `edit` 字段） |
| `refs/sp01/` | 新增人物（宋工、宋念三个年龄段、2058 年的波爷）、场景与道具参考图 |
| `episodes/sp01/clips/`、`alt/` | 每个镜头的选用条与全部备选条，`takes.json` 为选用表 |
| `episodes/sp01/storyboard/` | 分镜图（JPEG），`superseded/` 为被替换的版本 |
| `episodes/sp01/prompts/` | 每条视频实际提交的提示词、种子与输入图；导演台记录（检索到的词条编号与标题、模型输出、校验与修复）；MiniMax IR 对照文档 |
| `episodes/sp01/audio_qc.json` | 自动试听：对白逐字比对、三模型投票判断是否有配乐 |
| `episodes/sp01/tools/` | 本片的流水线、导演台（DeepSeek 提示词编译、校验与修复、小型检索、固定风格预设）和剪辑脚本 |

制作方式：分镜图与参考图由 gpt-image-2.6-sunburst 生成；视频由 AutoDL 上的 MiniMax H3 INT8 工作流生成，每条输入为分镜图加随机参考图，共 2 至 5 张；提示词由导演台按标准六段格式编写，每个年代锁定一套外观组合（风格预设），检索到的镜头语言词汇只作参考。
