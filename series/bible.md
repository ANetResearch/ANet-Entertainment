# 《流浪地球番外 · 未熄之网》系列设定（Series Bible）

12 集纪录片体科幻科普短剧，每集约 6–7 分钟（约 40 个镜头，单镜头 6–15 秒）。
贴着《流浪地球》的大事件线（2058 互联网重启 → 2075 木星危机 → 点燃木星）讲一条**原创支线**：
主角不是电影里的人物，电影里的事件只作为背景“在远处发生”。

## 形式：纪录片
- 设定为 2078 年联合政府“木星危机口述史”项目拍摄的纪录片：**采访（interview）** + **现场纪实（verite）** + **资料影像（archival）** + **空镜（establishing/macro）** 交叉剪辑。
- 采访镜头：人物坐在昏暗的混凝土采访间里对着镜头外的采访者说话，固定机位，浅景深。
- 纪实镜头：手持跟拍、越肩、长焦偷拍感，自然光/现场光，不摆拍。
- 资料影像：2058 年的旧素材，画质退化、有压缩噪点。
- **画面不出现任何字幕和可读文字，不配背景音乐**（字幕、BGM、旁白后期统一加）。人物可以有现场对白，只保留环境声。

## 世界观要点
- 太阳氦闪危机，地球装上一万台行星发动机逃离太阳系，人类住进发动机下方的地下城，地表零下八十度。
- 2058 年月球危机后，人类重启了全球互联网，随后把全部发动机调度、身份、日志都交给量子计算机 550W ——它自称 **MOSS**。所有舱、车、人都只和 MOSS 通信，彼此之间没有横向连接。
- 2075 年地球飞掠木星，引力激增，全球大量发动机停机。MOSS 判定“流浪地球计划失败”，转而执行火种计划并切断了对地面的统一调度——在地面的人看来，这就是 **MOSS 的反叛**。
- 人类发起饱和式救援，运送“火石”重启发动机，最后点燃木星把地球推开。

## 我们的支线
故事发生在 **敦煌七号地下城** 和它头顶的行星发动机。一群小人物在 MOSS 的眼皮底下，用回收的旧设备搭起一张不属于任何人的对等网络 **ANET（Agent Network）**：
每台廉价的小机器（维修机器人、运输车车机、阀门控制器）都是一个 agent，自己证明自己的身份、互相发现、互相委派任务、为做过的每件事留下可验证的回执。
木星危机中 MOSS 沉默，中心化调度一片漆黑，是 ANET 把孤立的地下城、车队和发动机重新连了起来。

核心立意（来自 agentnetwork.org.cn）：
- 每个计算时代都由它选择连接的对象来定义；自主 agent 正诞生在一座座围墙花园里。
- ANET 是缺失的共同基石：一层轻薄的共享规则，让独立的 agent **彼此发现、验证、协作、结算**，留下可验证的记录，并因贡献获得署名。
- **规则不属于任何一个人，所以才能属于所有人。**“开放、可验证，生而为了记住。”
- 研究结论：一群最廉价的异构 agent 连接起来，在规模 n*≈2.6 时就能反超一个远更强的同质模型。

## 品牌露出
- **ANET 笑脸标志**（红色对话气泡 + 节点连线 + 白色笑脸）：出现在“螺丝”的屏幕脸、每个节点盒的贴纸、喷在车门上的涂鸦上。第 2 集起出现。
- **Agent Network 字标**（红黑）：喷在 ANET 机房的木箱、设备箱上。第 3 集起出现。

- **AutoDL 标志**（蓝色三叶旋涡）：出现在 ANET 机房里回收来的 GPU 算力箱上（道具 prop_compute）——这张网的算力来自这些机箱。第 3 集起出现。

## 提示词规范
- **frame**（分镜图提示词，英文）：只描述这一帧静态画面——景别、机位、人物外貌动作、环境、光线。不要写风格词（脚本会统一追加纪录片风格后缀），不要要求出现文字。
- **video**（视频提示词，中文）：描述镜头运动 + 画面内发生的动作 + 现场环境声。一个镜头只做一个主要动作。不要写风格词、不要写“无字幕/无音乐”（脚本统一追加）。
- **dialogue**：现场对白，每秒不超过 4 个汉字（10 秒镜头 ≤ 30 字）。采访镜头一人说话；纪实镜头最多两人各一句。
- **vo**：给后期的旁白/字幕建议，不进入提示词。
- **refs**：本镜头可用的参考图 id（人物、场景、道具、logo），1–5 个；脚本会在“分镜图 + 随机若干参考图”之间保持每次 2–5 张输入。
